# ahar-vsvis

A lightweight but powerful visualization tool for `ahar` (agent-harnesses standard)-powered
repos: a VS Code extension that observes a running Claude Code session and visualizes its
navigation against the harness/sub-harness structure it's exploring.

This repo is currently just an init commit — no code yet. Design context and the reasoning
behind this project's shape live in the `toprope-agentdev` meta-repo's diary:
[`references/diary/2026-08-18-1007-vs-code-base-or-extension.md`](https://github.com/agentharnesses/toprope-agentdev/blob/main/references/diary/2026-08-18-1007-vs-code-base-or-extension.md).
